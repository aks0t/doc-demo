= CRM Leads API

Демо проект технической документации для REST API управления лидами (leads) —
модуля учебной XRM-платформы. Проект показывает подход Docs-as-Code:
документация хранится в Git рядом со спекой, собирается через Antora и публикуется через CI/CD.

== О проекте

CRM Leads API — небольшой REST-сервис, позволяющий:

* создавать и получать лиды;
* обновлять статус лида (новый, в работе, квалифицирован, закрыт);
* удалять лиды;
* получать токен доступа для аутентификации запросов.

Документация описывает API на основе OpenAPI-спецификации (см. link:https://github.com/aks0t/doc-demo/blob/main/openapi/openapi.yaml[openapi/openapi.yaml])
