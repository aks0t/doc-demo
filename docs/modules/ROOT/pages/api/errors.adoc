= Ошибки и коды состояния

== Формат ошибки

Все ошибки возвращаются в едином формате:

[source,json]
----
{
  "error": {
    "code": "validation_error",
    "message": "Поле email обязательно для заполнения",
    "field": "email"
  }
}
----

== Коды состояния HTTP

[cols="1,2,3"]
|===
| Код | Значение | Когда возникает

| 200 OK
| Успешно
| Запрос выполнен, данные возвращены.

| 201 Created
| Создано
| Ресурс успешно создан (например, `POST /leads`).

| 204 No Content
| Успешно, без тела ответа
| Ресурс успешно удалён (`DELETE /leads/\{id\}`).

| 400 Bad Request
| Невалидные данные
| Не хватает обязательных полей или данные не проходят валидацию.

| 401 Unauthorized
| Не авторизован
| Токен отсутствует, истёк или недействителен.

| 403 Forbidden
| Доступ запрещён
| Токен валиден, но недостаточно прав на операцию.

| 404 Not Found
| Не найдено
| Ресурс с указанным `id` не существует.

| 409 Conflict
| Конфликт
| Например, лид с таким email уже существует.

| 429 Too Many Requests
| Превышен лимит
| Слишком много запросов за короткий период (rate limiting).

| 500 Internal Server Error
| Ошибка сервера
| Непредвиденная ошибка на стороне сервера.
|===

== Коды ошибок бизнес-логики

[cols="1,3"]
|===
| `code` | Описание

| `validation_error`
| Одно или несколько полей не прошли валидацию.

| `duplicate_email`
| Лид с таким email уже существует.

| `lead_not_found`
| Лид с указанным `id` не найден.

| `invalid_status_transition`
| Недопустимый переход между статусами. Подробнее см. xref:api/endpoints/leads.adoc#_диаграмма_статусов[диаграмму статусов].
|===
