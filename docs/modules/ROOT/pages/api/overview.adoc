= Обзор API

== Общие сведения

* Базовый URL: `https://api.example-crm.dev/v1`
* Формат данных: JSON (`Content-Type: application/json`)
* Аутентификация: Bearer-токен (см. xref:guides/authentication.adoc[Аутентификация])
* Даты — в формате ISO 8601, UTC (`2026-07-27T09:00:00Z`)
* Идентификаторы — строки вида `ld_XXXX`

== Пагинация

Списочные эндпоинты поддерживают query-параметры:

[cols="1,1,3"]
|===
| Параметр | Тип | Описание

| `page`
| integer
| Номер страницы, по умолчанию `1`.

| `pageSize`
| integer
| Размер страницы, по умолчанию `20`, максимум `100`.
|===
