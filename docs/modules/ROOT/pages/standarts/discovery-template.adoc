= Шаблон discovery-отчёта

Этот документ — шаблон для проведения discovery-анализа перед разработкой или изменением API. Он помогает системно подойти к задаче, определить требования, ограничения и влияние изменений.

== Процесс анализа

Новая задача проходит через обязательный discovery-этап, после которого принимается решение о сценарии работ (новый функционал или доработка существующего). Общая схема процесса:

[mermaid]
....
flowchart TD
    A[Новая задача] --> B[Discovery-анализ]
    B --> C{Новый функционал?}
    C -->|Да| D[Greenfield]
    C -->|Нет| E[Legacy]
    D --> F[Проектирование]
    E --> G[Анализ влияния]
    F --> H[API Design + OpenAPI]
    G --> H
    H --> I[Разработка]
    I --> J[Документация]
....

* Есть ли документация текущего поведения?
