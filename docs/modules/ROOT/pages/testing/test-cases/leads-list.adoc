= Список лидов

Тест-кейсы на экран списка лидов Admin UI. Экран отображает данные из
`GET /leads` и поддерживает фильтр по статусу (`status`) и пагинацию
(`page`/`pageSize`) — см. xref:api/endpoints/leads.adoc#_get_leads[Leads API].

== Таблица кейсов

[cols="1,3,3,3,1,1"]
|===
| ID | Предусловия | Шаги | Ожидаемый результат | Приоритет | Тип

| TC-LIST-01
| Пользователь авторизован, в системе есть лиды в разных статусах
| 1. Открыть список лидов
| Отображается таблица лидов: колонки `ID`, `Имя`, `Email`, `Телефон`, `Источник`, `Статус`, `Дата создания`; данные соответствуют ответу `GET /leads`
| High
| Позитивный

| TC-LIST-02
| Пользователь авторизован, есть лиды в разных статусах
| 1. Открыть список лидов +
2. Выбрать фильтр «Статус: new»
| Отображаются только лиды со статусом `new`; в запросе к API присутствует `status=new` (проверяется в DevTools/Network)
| High
| Позитивный

| TC-LIST-03
| Пользователь авторизован, открыт список лидов
| 1. Выбрать фильтр «Статус: qualified»
| Отображаются только лиды со статусом `qualified`; API вернул `200` с отфильтрованным списком
| Medium
| Позитивный

| TC-LIST-04
| Пользователь авторизован, открыт список лидов
| 1. Перейти на следующую страницу пагинации

| Medium
| Позитивный

| TC-LIST-05
| Пользователь авторизован, список пуст (нет лидов)
| 1. Открыть список лидов
| Отображается пустое состояние: «Лидов нет»; нет ошибок в консоли; таблица скрыта
| Medium
| Позитивный

| TC-LIST-06
| Пользователь авторизован, открыт список лидов
| 1. Сменить фильтр, пока не выбрано «Статус: closed» +
2. Проверить, что в системе нет лидов со статусом `closed`
| Отображается пустое состояние с текстом «Лидов со статусом closed нет» (подтверждает корректную фильтрацию)
| Low
| Позитивный

| TC-LIST-07

| Medium
| Адаптив

| Medium
| Негативный

| TC-LIST-09
| Пользователь авторизован, открыт список лидов
| 1. Пройтись по таблице и пагинации с клавиатуры (Tab/Shift+Tab) +
2. Убедиться в видимом фокусе на строках/элементах управления
| Таблица списка читается скринридером (корректные `<th>` и роль таблицы); все элементы управления (фильтр, пагинация, кнопки) доступны с клавиатуры; видимый focus-индикатор присутствует
| Medium
| Accessibility
|===

== Примечания

Запрос `GET /leads` с фильтром и пагинацией описан в
xref:api/endpoints/leads.adoc#_get_leads[Leads API], пример ответа — `200 OK`
с полями `items`, `page`, `pageSize`, `totalItems`.
