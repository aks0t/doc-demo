= Логин и аутентификация

Тест-кейсы на форму логина Admin UI. Форма отправляет `POST /auth/token` с
полями `clientId` и `clientSecret` (см. xref:api/endpoints/auth.adoc#_post_auth_token[Auth API]).

== Таблица кейсов

[cols="1,3,3,3,1,1"]
|===
| ID | Предусловия | Шаги | Ожидаемый результат | Приоритет | Тип

| TC-AUTH-01
| Открыта форма логина
| 1. Ввести валидные `clientId` и `clientSecret` +
2. Нажать «Войти»
| Пользователь авторизован, открыт список лидов; токен сохранён в браузере (для последующих запросов)
| High
| Позитивный

| TC-AUTH-02
| Открыта форма логина
| 1. Ввести неверный `clientSecret` (остальные поля корректны) +
2. Нажать «Войти»
| Показывается ошибка «Неверные учётные данные», форма не отправлена повторно; запрос `POST /auth/token` вернул `401 invalid_credentials` (проверяется в DevTools/Network)
| High
| Негативный

| TC-AUTH-03
| Открыта форма логина
| 1. Оставить оба поля пустыми +
2. Нажать «Войти»
| Оба поля подсвечены как обязательные; отправка не выполняется; запрос `POST /auth/token` не отправляется
| Medium
| Негативный

| TC-AUTH-04
| Открыта форма логина, поля заполнены невалидными значениями
| 1. Ввести только `clientId` +
2. Нажать «Войти»
| Поле `clientSecret` подсвечено как обязательное с сообщением об ошибке; запрос не отправляется
| Medium
| Негативный

| TC-AUTH-05
| Пользователь авторизован, токен истёк (3600 сек), открыта любая страница со списком лидов
| 1. Выполнить действие, требующее авторизации (например, открыть список лидов)
| При получении `401 Unauthorized` пользователь перенаправляется на форму логина с сообщением «Сессия истекла»; после повторного входа данные не теряются
| High
| Негативный
|===

== Связь с API

Каждый негативный кейс проверяет не только сообщение на экране, но и то, что
интерфейс обрабатывает **именно тот код ошибки**, который возвращает API:

* `401 invalid_credentials` — xref:api/errors.adoc#_коды_ошибок_бизнес_логики[Ошибки и коды состояния] →
  TC-AUTH-02;
* `validation_error` (обязательные поля) — xref:api/endpoints/auth.adoc#_возможные_ошибки[Auth API] →
  TC-AUTH-03, TC-AUTH-04;
* `401 unauthorized` (истёкший токен) → TC-AUTH-05.

Детали по срокам жизни токена — в xref:guides/authentication.adoc#_получение_токена[Аутентификация].
