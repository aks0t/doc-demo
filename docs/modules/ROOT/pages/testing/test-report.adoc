== Вывод

**Не готово к релизу** — два открытых дефекта severity Major. Оба связаны с
некорректным отображением ошибок контракта (`duplicate_email`,
`invalid_status_transition`) и должны быть исправлены до выката:

1. BR-001: отображать сообщение `duplicate_email` под полем email.
2. BR-002: отображать сообщение `invalid_status_transition` у элемента выбора
   статуса.

После исправления — повторный прогон кейсов `TC-FORM-07`, `TC-STATUS-05`,
`TC-STATUS-06` и закрытие дефектов.
