= Архитектура пайплайна документации

Описан процесс сборки и доставки документации от пуша в Git до публикации на GitHub Pages.

== Диаграмма развертывания

[mermaid, width=1200]
....
flowchart LR
    A[Разработчик пушит в main] --> B[GitHub Actions: workflow Publish Docs]

    subgraph build[Сборка]
        B --> C[Checkout репозитория]
        C --> D[Установка Node.js 20]
        D --> E[npm ci]
        E --> F[Ожидание Kroki<br/>health-check]
        F --> G[Antora сборка сайта]
        G --> H[Публикация OpenAPI<br/>в build/site/openapi]
        H --> I[Загрузка артефакта<br/>upload-pages-artifact]
    end

    I --> J[Деплой]

    subgraph deploy[Деплой]
        J --> K[deploy-pages]
        K --> L[GitHub Pages]
    end

    L --> M[Документация доступна пользователям]
    L --> N[OpenAPI спецификация<br/>/openapi/openapi.yaml]

    subgraph Services[Сервис-контейнеры Docker]
        S1[Kroki:8000]
        S2[mermaid]
        S3[bpmn]
    end

    F -.- S1

    %% Failure paths
    E -.->|Ошибка| X[Build failed]
    F -.->|Ошибка| X
    G -.->|Ошибка| X
    H -.->|Ошибка| X
    K -.->|Ошибка| Y[Deploy failed]

    X --> Z[Уведомление разработчика]
    Y --> Z
....
